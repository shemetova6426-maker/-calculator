# Семейный бюджет

Веб-приложение для учёта семейных доходов и расходов. Работает полностью в браузере: данные сохраняются локально и не отправляются на сервер.

## Возможности

- Добавление, редактирование и удаление операций
- Категории доходов и расходов
- Итоги: доход, расход, баланс
- Диаграмма структуры расходов
- Норма сбережений
- Поиск и фильтры (тип, категория, месяц)
- Выбор валюты (RUB, EUR, USD, KZT, BYN)
- Экспорт в CSV
- Демо-данные для быстрого старта
- Автосохранение в `localStorage`

## Быстрый старт

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
npm start
```

После запуска сайт будет доступен по адресу, который покажет `serve` (обычно http://localhost:3000).

## Использование

1. Откройте лендинг и нажмите **Начать учёт**
2. Добавьте доход или расход через форму
3. При необходимости нажмите **Добавить пример**, чтобы увидеть демо-данные
4. Анализируйте итоги, диаграмму и историю операций
5. При необходимости экспортируйте CSV
